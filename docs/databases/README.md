# Databases

A database is an organised collection of organised data along with a system to manage the data.

## [SQL Databases](relational-databases.md)
SQL (relational) databases store data as rows and columns in tables with predefined schemas and are queried using the [SQL query language][sql-language]. SQL databases can be **row based** (SQLite/[GeoPackage](geopackage.md)) or **column based** ([Duck DB](duckdb.md)).
